# Security Policy

## Supported Versions

This repository is currently maintained on the `main` branch only.

## Reporting a Vulnerability

If you discover a security issue in this extension, please report it privately to the repository owner instead of opening a public issue with exploit details.

When reporting, include:

- A short description of the issue
- Steps to reproduce
- Expected and actual behavior
- Any relevant screenshots or console output

## Security Posture

- The extension is restricted to the `https://na.myconnectwise.net/` host.
- It uses Chrome Manifest V3 and does not load remote code.
- Only the minimum `tabs` permission required for tab restoration is requested.
